# Week 8 meeting script

## Context

Our problem-space sentence: teams of software developers and architects lose context when sharing LLM queries and results via fragmented tools like Telegram, and need a unified space to aggregate and build upon these interactions.

This script is reconstructed from the team's brief account for [#391](https://github.com/WellMadeTeam/workspace-ai-03/issues/391); it is not evidence of preparation before the meeting or of the exact questions asked.
The agenda and timeboxes below describe a suggested 30-minute structure, not the meeting's measured duration.
The team had Markdown support to demonstrate and a usability test to revisit.
Target: check whether the demonstrated Markdown behavior is ready for acceptance and confirm the usability test's execution during SPRINT-08.

## Agenda

1. Permission questions (2 min).
   Show: nothing.
   Questions 1–3.
2. Markdown demonstration (12 min).
   Show: Markdown in text blocks and AI conversation messages against [FR-024](../../docs/functional-requirements/fr/FR-024.md) and [US-19](https://github.com/WellMadeTeam/workspace-ai-03/issues/324).
   Questions 4–5.
3. Usability test and previous follow-ups (13 min).
   Show: the [UT-01 design](../../docs/usability-tests/ut-01/README.md), the [Week 7 action points](../week-07/meeting-report.md#action-points), and the [Week 7 open questions](../week-07/meeting-report.md#open-questions).
   Questions 6–9.
4. Read back decisions and action points (3 min).
   Show: the note taker's list, including unresolved Markdown behavior and the usability test's timing.
   Question 10.

## Questions

1. _(closed)_ May we record this meeting?
2. _(closed)_ May we publish a sanitized transcript in the repository?
3. _(closed)_ If publication is refused, may we share the transcript privately with the instructors?
4. _(open)_ Where does the Markdown rendering shown differ from the formatting you expect?
5. _(closed)_ Does the demonstrated behavior satisfy US-19's acceptance criteria, or does any rendering problem leave acceptance open?
6. _(open)_ What, if anything, in the UT-01 design still needs changing before the sessions?
7. _(closed)_ Can we confirm that the usability test will run during SPRINT-08?
8. _(open)_ Which three kinds of diagrams do you use most?
9. _(open)_ How should we handle the control group if recruitment numbers are low?
10. _(open)_ What needs correcting in the decisions and action points we have just read back?
