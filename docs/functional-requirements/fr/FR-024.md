# FR-024: Render Basic Markdown In Blocks And AI Conversations

- **Status:** Active
- **Traces to:** [`US-19`](https://github.com/WellMadeTeam/workspace-ai-03/issues/324)
- **Containers:** `frontend`, `backend`

## Behavior

The product shall render headings, emphasis, ordered and unordered lists, inline code, and fenced code in text blocks and AI conversations.

The product shall preserve the original Markdown source when members edit a text block and when its content is saved and reloaded.

The product shall keep Mermaid diagram rendering in AI conversations and render other fenced code as code.

The product shall display plain text and incomplete Markdown delimiters as readable content.

The product shall not execute raw HTML, scripts, or event handlers in block or conversation content.

## Acceptance Criteria

### AC-01

Given a text block or AI conversation containing the supported Markdown, when a member views it on the board or in the side panel, then headings, emphasis, lists, inline code, and fenced code are rendered.

### AC-02

Given a member edits a Markdown text block and saves it, when another member views it or the board is reloaded, then the same Markdown source is retained and rendered.

### AC-03

Given an AI conversation containing a valid or invalid Mermaid fence and a normal code fence, when a member views the conversation, then Mermaid keeps its existing rendered or error behavior and the normal code fence is shown as code.

### AC-04

Given plain text, incomplete Markdown delimiters, or unsafe raw HTML in a block or conversation, when a member views the content, then the text remains readable and no script or event handler executes.
