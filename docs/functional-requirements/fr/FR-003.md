# FR-003: Show Board Changes To Every Member

- **Status:** Active
- **Traces to:** [`US-01`](https://github.com/WellMadeTeam/workspace-ai-03/issues/37), [`DEC-012`](../../decisions.md#dec-012)
- **Containers:** `frontend`, `backend`

## Behavior

When a member adds, moves, or edits a block, the product shall show the change on the board of every other member who has it open, without a reload.

While a member is moving or editing a block, the product shall not overwrite that block with an older state from the server.

## Acceptance Criteria

### AC-01

Given two members on one board, when one moves a block, then the other sees it at the new position without reloading, within the time `QR-01` sets.

### AC-02

Given a member typing in a text block, when the board refreshes from the server before the typed text is sent, then the block still shows the typed text.
