# FR-015: Sign Up For An Account

- **Status:** Active
- **Traces to:** [`US-11`](https://github.com/WellMadeTeam/workspace-ai-03/issues/47)
- **Containers:** `frontend`, `backend`

## Behavior

When a new person signs up with a name and a password, the product shall create an account that keeps the boards that person creates.

## Acceptance Criteria

### AC-01

Given a new person, when they sign up and create a board, then that board is in their account's list of boards.
