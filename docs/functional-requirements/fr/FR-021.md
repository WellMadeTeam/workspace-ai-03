# FR-021: Clear An AI Block's Context

- **Status:** Active
- **Traces to:** [`US-16`](https://github.com/WellMadeTeam/workspace-ai-03/issues/228), [`DEC-031`](../../decisions.md#dec-031)
- **Containers:** `frontend`, `backend`

## Behavior

When a member clears an AI block, the product shall remove the block's queries and replies for every member and shall keep the block's name and its connections.

When a member sends a query from a cleared AI block, the product shall send none of the cleared queries and replies to the LLM service provider.

When a cleared AI block is connected to other blocks, the product shall keep sending their content as the query's context and showing the blocks each reply used.

## Acceptance Criteria

### AC-01

Given an AI block with a conversation and a connection, when a member clears it, then every member sees the block with no messages, its name, and its connection, also after a reload.

### AC-02

Given an AI block whose conversation held a made-up code word and that is connected to nothing, when a member clears it and asks it for the code word, then the reply does not contain it.

### AC-03

Given a cleared AI block connected to block A, which holds a made-up code word, when a member asks it for the code word, then the reply contains it and lists A.
