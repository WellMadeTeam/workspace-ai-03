# FR-013: Show An LLM Image

- **Status:** Active
- **Traces to:** [`US-09`](https://github.com/WellMadeTeam/workspace-ai-03/issues/45), [`DEC-010`](../../decisions.md#dec-010)
- **Containers:** `frontend`, `backend`

## Behavior

When a member asks an AI block for an image and the LLM service provider returns one, the product shall show the same image in that block to every member.

When image generation fails, the product shall show an error on that block to every member.

## Acceptance Criteria

### AC-01

Given a member asks for an image, when it arrives, then every member sees the same image in that block.

### AC-02

Given image generation fails, when a member asks for an image, then every member sees an error on that block.
