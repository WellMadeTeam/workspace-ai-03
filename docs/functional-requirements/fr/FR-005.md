# FR-005: Answer A Query In An AI Block

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/WellMadeTeam/workspace-ai-03/issues/40), [`ADR-001`](../../architecture/adr/ADR-001.md), [`ADR-003`](../../architecture/adr/ADR-003.md)
- **Containers:** `frontend`, `gateway`, `backend`

## Behavior

When a member sends a query from an AI block, the product shall send the block's conversation to the LLM service provider and shall store the query and the reply in that block.

The product shall show an AI block's queries and replies to every member who opens that block.

## Acceptance Criteria

### AC-01

Given two members on one board, when one sends a query from an AI block, then both see the query and the reply from AI to this query in that block's messages.

### AC-02

Given an AI block with a stored query and reply, when the page is reloaded, then the block still shows both.
