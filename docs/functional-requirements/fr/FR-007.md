# FR-007: Use Connected Blocks As A Query's Context

- **Status:** Active
- **Traces to:** [`US-05`](https://github.com/WellMadeTeam/workspace-ai-03/issues/41), [`DEC-005`](../../decisions.md#dec-005), [`DEC-029`](../../decisions.md#dec-029), [`DEC-032`](../../decisions.md#dec-032), [`ADR-003`](../../architecture/adr/ADR-003.md)
- **Containers:** `frontend`, `backend`
- **Changed:**
  - A connected AI block passes its conversation on as context, with the statement and `AC-03` added, per [`DEC-029`](../../decisions.md#dec-029).
  - A connected AI block's conversation longer than the size threshold is passed on as a summary, with the statement and `AC-04` added, per [`DEC-032`](../../decisions.md#dec-032).

## Behavior

When a member connects a block to an AI block and sends a query from it, the product shall send the connected blocks' content to the LLM service provider along with the query.

When a connected block is an AI block, the product shall send its conversation as that block's content.

When a connected AI block's conversation is longer than the size threshold, the product shall send a summary of that conversation instead of the whole of it.

When an AI block is connected to nothing, the product shall send its query without the content of any other block.

## Acceptance Criteria

### AC-01

Given block A whose content holds a made-up code word, connected to AI block C, when a member asks in C for the code word, then the reply in C contains it.

### AC-02

Given the same block A, when a member asks an AI block D that is connected to nothing for the code word, then the reply in D does not contain it.

### AC-03

Given AI block A whose conversation holds a made-up code word, connected to AI block C, when a member asks in C for the code word, then the reply in C contains it.

### AC-04

Given AI block A whose conversation is longer than the size threshold, connected to AI block C, when a member sends a query from C, then the context sent with the query holds a summary of A's conversation and not the whole of it.
