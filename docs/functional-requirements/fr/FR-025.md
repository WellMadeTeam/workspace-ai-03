# FR-025: Copy Selected Blocks And Connections

- **Status:** Active
- **Traces to:** [`US-01`](https://github.com/WellMadeTeam/workspace-ai-03/issues/37)
- **Containers:** `frontend`, `backend`

## Behavior

When a member selects blocks and presses Ctrl+C followed by Ctrl+V outside a text editor, the product shall create independent copies on the same board with new identifiers and a visible position offset, preserving their relative positions.
The product shall also accept Cmd+C and Cmd+V on macOS.
The product shall preserve text and image content and each AI block's stored conversation, including system messages and historical context references, as they exist when the paste is processed.
The product shall copy a connection only when the connection itself and both endpoint blocks were selected when the member copied the selection, joining the corresponding new blocks.
The product shall leave the originals unchanged and persist the copies so every member sees them without reloading, per [FR-003](FR-003.md).
When focus is in a text editor or a member has selected text, the product shall preserve native text clipboard behavior.
The product shall limit the block clipboard to the current board and clear it when the member changes boards.

## Acceptance Criteria

### AC-01

Given selected text, AI, and image blocks, when a member copies and pastes them, then new blocks have the same titles and content, the AI block has an independent conversation in the same order, and the originals remain unchanged.

### AC-02

Given a selected connection and both selected endpoint blocks, when a member copies and pastes them, then a new connection joins the new blocks.
An unselected connection or a connection with either endpoint unselected is not copied.

### AC-03

Given copied blocks, when a member pastes repeatedly, then each group has new identifiers and an increasing visible offset while preserving relative positions.
The groups remain after reload and appear for another member without reload.

### AC-04

Given focus in a block's title, text editor, or query composer, or a text selection in a reply, when the member copies or pastes text, then native text clipboard behavior works and no blocks are duplicated.

### AC-05

Given a copied selection whose source block or included connection was deleted, when the member pastes, then the product shows an error and creates no partial copies.
