# FR-014: Use A Reference Document As Context

- **Status:** Active
- **Traces to:** [`US-10`](https://github.com/WellMadeTeam/workspace-ai-03/issues/46)
- **Containers:** `frontend`, `backend`

## Behavior

When a member adds a reference document to the board and connects it to an AI block, the product shall send the document's content to the LLM service provider along with the block's query.

When a member adds a file of a type the product does not support, the product shall not add it and shall say why.

## Acceptance Criteria

### AC-01

Given a document holding a made-up code word connected to an AI block, when a member asks the block for the code word, then the reply contains it.

### AC-02

Given a file of an unsupported type, when a member adds it, then no block is added and the member sees that the type is not supported.
