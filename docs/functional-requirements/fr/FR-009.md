# FR-009: Add A Text Note

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/WellMadeTeam/workspace-ai-03/issues/39)
- **Containers:** `frontend`, `backend`

## Behavior

When a member adds a text block at a spot on the board and types in it, the product shall show the block with that text at that spot to every member.

## Acceptance Criteria

### AC-01

Given an empty spot on the board, when a member adds a text block there and types `note`, then every member sees a block with `note` at that spot after a reload.
