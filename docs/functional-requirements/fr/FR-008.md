# FR-008: Show The Blocks A Reply Used

- **Status:** Active
- **Traces to:** [`US-06`](https://github.com/WellMadeTeam/workspace-ai-03/issues/42), [`DEC-014`](../../decisions.md#dec-014), [`DEC-028`](../../decisions.md#dec-028)
- **Containers:** `frontend`, `backend`
- **Changed:**
  - A reply lists the blocks it used among those sent as its context rather than every block sent, `AC-01` was edited in place, and `AC-04` was added for a reply that used no block, per [`DEC-028`](../../decisions.md#dec-028).

## Behavior

When the product sends a query to the LLM service provider with blocks as its context, it shall record, for that reply, which of those blocks the reply used.

The product shall show, by each reply, how many blocks it used as context and which ones.

When a reply used no block as context, the product shall show no block by that reply.

When a member picks one of the blocks listed by a reply, the product shall bring that block into view.

## Acceptance Criteria

### AC-01

Given an AI block connected to three blocks, of which only block A holds a made-up code word, when a member asks for the code word and the reply arrives, then the reply lists A and lists no block that is not connected to the AI block.

### AC-02

Given a reply built with blocks A and B as context, when the connection to B is removed, then that reply still lists A and B.

### AC-03

Given a reply that lists block A, when a member picks A, then the board brings A into view.

### AC-04

Given an AI block connected to nothing, when a member sends a query and the reply arrives, then the reply lists no block.
