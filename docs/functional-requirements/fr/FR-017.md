# FR-017: Export A Board

- **Status:** Active
- **Traces to:** [`US-13`](https://github.com/WellMadeTeam/workspace-ai-03/issues/49)
- **Containers:** `frontend`, `backend`

## Behavior

When a member exports a board, the product shall give them a file in a supported format with every block's content.

## Acceptance Criteria

### AC-01

Given a board with blocks, when a member exports it, then the file holds every block's content.

### AC-02

Given an empty board, when a member exports it, then the file is valid and holds no content.
