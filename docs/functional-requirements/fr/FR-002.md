# FR-002: Open A Board By Its Address

- **Status:** Active
- **Traces to:** [`US-07`](https://github.com/WellMadeTeam/workspace-ai-03/issues/43), [`DEC-004`](../../decisions.md#dec-004)
- **Containers:** `frontend`, `backend`

## Behavior

When a member opens the address of an existing board, the product shall show that board with the same rights every other member has.

When someone opens the address of a board that does not exist, the product shall show that the board was not found.

## Acceptance Criteria

### AC-01

Given a board with two blocks, when a second member opens its address in another browser, then that member sees the same two blocks and can move them.

### AC-02

Given an address whose board id does not exist, when someone opens it, then the page says the board was not found and shows no blocks.
