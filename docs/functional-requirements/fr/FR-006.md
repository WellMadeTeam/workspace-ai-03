# FR-006: Show A Failed Query's Error To Every Member

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/WellMadeTeam/workspace-ai-03/issues/40), [`DEC-018`](../../decisions.md#dec-018)
- **Containers:** `frontend`, `backend`

## Behavior

When the LLM service provider fails to answer a query, the product shall show an error in plain language on that AI block to every member who has the board open.

When a query fails, the product shall keep the query's text in the block.

## Acceptance Criteria

### AC-01

Given the LLM key is invalid, when a member sends a query, then every member with the board open sees on that block an error that names no exception, status code, or stack trace.

### AC-02

Given a failed query, when a member opens the block's messages, then the query's text is still shown.
