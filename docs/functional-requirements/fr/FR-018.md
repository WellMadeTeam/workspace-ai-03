# FR-018: Edit A Text Block In The Side Panel

- **Status:** Active
- **Traces to:** [`US-14`](https://github.com/WellMadeTeam/workspace-ai-03/issues/201), [`DEC-025`](../../decisions.md#dec-025)
- **Containers:** `frontend`, `backend`

## Behavior

When a member selects a text block, the product shall open the side panel with the block's full text, as it does for an AI block.

When a member edits a text block's text in the side panel, the product shall show the new text in that block to every member.

When a member types in a text block on the board while it is open in the side panel, the product shall show the same text in the side panel.

## Acceptance Criteria

### AC-01

Given a text block whose text is longer than the block shows, when a member selects it, then the side panel opens and shows the block's full text.

### AC-02

Given a text block open in the side panel, when a member edits its text there, then every member sees the new text in that block, also after a reload.

### AC-03

Given a text block open in the side panel, when a member types in the block on the board, then the side panel shows the same text.
