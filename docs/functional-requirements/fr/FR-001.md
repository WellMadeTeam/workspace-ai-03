# FR-001: Create A Board On The First Visit

- **Status:** Active
- **Traces to:** [`US-01`](https://github.com/WellMadeTeam/workspace-ai-03/issues/37), [`ADR-001`](../../architecture/adr/ADR-001.md)
- **Containers:** `frontend`, `backend`

## Behavior

When a member opens the product without a board address, the product shall create a new, empty board and shall put its address in the browser's address bar.

When a member opens the product with a board address, the product shall not create a board.

## Acceptance Criteria

### AC-01

Given no board address, when a member opens the product, then the address bar shows a `?board=<id>` address and the board is empty.

### AC-02

Given a board address, when a member opens it and reloads the page, then the address stays the same and no new board is created.
