# FR-019: Rename A Block

- **Status:** Active
- **Traces to:** [`US-14`](https://github.com/WellMadeTeam/workspace-ai-03/issues/201), [`DEC-025`](../../decisions.md#dec-025)
- **Containers:** `frontend`, `backend`

## Behavior

When a member renames a text block or an AI block, the product shall show the new name on that block to every member.

When a member clears a block's name and finishes renaming, the product shall give the block the default name of its kind.

## Acceptance Criteria

### AC-01

Given a text block and an AI block, when a member renames each of them in the same way, then every member sees both new names, also after a reload.

### AC-02

Given a named text block, when a member clears its name and finishes renaming, then every member sees the block named `Text`.
