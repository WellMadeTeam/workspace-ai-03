# FR-012: Render An LLM Diagram

- **Status:** Active
- **Traces to:** [`US-08`](https://github.com/WellMadeTeam/workspace-ai-03/issues/44), [`DEC-010`](../../decisions.md#dec-010), [`DEC-019`](../../decisions.md#dec-019), [`DEC-033`](../../decisions.md#dec-033)
- **Containers:** `frontend`
- **Changed:**
  - The rendered diagram shows together with its source text, which a member can copy and collapse, instead of replacing the code, `AC-01` was edited in place, and `AC-03` was added, per [`DEC-033`](../../decisions.md#dec-033).

## Behavior

When an LLM reply contains a diagram in Mermaid, the product shall show the rendered diagram in that AI block to every member, together with the diagram's source text.

The product shall let a member copy a diagram's source text and collapse it.

When the diagram code cannot be rendered, the product shall show the code as text with a note that it could not be rendered.

## Acceptance Criteria

### AC-01

Given a reply holding a valid Mermaid diagram, when it arrives, then every member sees the rendered picture in the AI block together with its source text.

### AC-02

Given a reply holding invalid Mermaid code, when it arrives, then members see the code as text and the note.

### AC-03

Given a rendered diagram with its source text, when a member collapses the source text and then copies it, then the picture stays in view, and the clipboard holds the diagram's source text exactly as the reply gave it.
