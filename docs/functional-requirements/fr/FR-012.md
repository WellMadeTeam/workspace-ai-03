# FR-012: Render An LLM Diagram

- **Status:** Active
- **Traces to:** [`US-08`](https://github.com/WellMadeTeam/workspace-ai-03/issues/44), [`DEC-010`](../../decisions.md#dec-010), [`DEC-019`](../../decisions.md#dec-019)
- **Containers:** `frontend`

## Behavior

When an LLM reply contains a diagram in Mermaid, the product shall show the rendered diagram to every member.

When the diagram code cannot be rendered, the product shall show the code as text with a note that it could not be rendered.

## Acceptance Criteria

### AC-01

Given a reply holding a valid Mermaid diagram, when it arrives, then every member sees a picture instead of the code.

### AC-02

Given a reply holding invalid Mermaid code, when it arrives, then members see the code as text and the note.
