# QR-04: Bring The Product Up From The Setup Page In Ten Minutes

The customer brings the product up on his own computer by following the setup page, in under ten minutes and without changing any code.

- **Status:** Active
- **Characteristic:** Flexibility
- **Sub-characteristic:** Installability
- **Business importance:** Medium
- **Technical risk:** Low

## Scenario

### Source

The customer, who runs the product himself, as [`CON-02`](../../product-vision.md#con-02) requires.

### Stimulus

The customer wants a working board on his own computer.

### Environment

A computer with Docker installed, a clean checkout of `main`, and a key for the LLM service provider.

### Artifact

The setup page [`docs/setup.md`](../../setup.md) and the containers it starts.

### Response

Following only the setup page, the customer starts every container, opens the board in a browser, and gets an AI block's reply.

### Response Measure

On a first run with no images cached, the board opens and answers a query within 10 minutes of the first command, after setting only the LLM key, with no file in `app/` edited.
